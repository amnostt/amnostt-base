## Users

## Product Purpose

Amnostt Base es una base reutilizable para aplicaciones web. Su referencia implementada combina autenticación y sesiones seguras con Tasks como ejemplo de gestión autorizada. Los proyectos derivados deben describir aquí su propósito específico sin asumir que las áreas futuras de la base ya existen.

## Operating Context

Workspace con pnpm, API NestJS, web React/Vite y PostgreSQL mediante Prisma. Para el estado real de Auth, Tasks, seguridad y sus límites, consulta [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md).

## Brand Commitments

El nombre de esta base es Amnostt Base. La documentación técnica usa español profesional neutro; el copy visible de la aplicación permanece en inglés salvo decisión explícita del proyecto derivado.
