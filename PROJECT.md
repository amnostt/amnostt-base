# Project Overview

This project is a reusable base application for future projects.

## Confirmed decisions

- **Repository:** monorepo managed with pnpm
- **Frontend:** React with Vite
- **Backend:** NestJS
- **Communication:** REST API
- **Database:** PostgreSQL
- **Data access:** Prisma

## Initial scope

- Authentication with registration and login
- One reference CRUD feature

Specific implementation and architecture decisions not listed here remain open.
