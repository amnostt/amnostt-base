# Angular starter

This is an independent Angular 22 single-page application. It is intentionally
limited to a routed shell and does not implement product or authentication
behavior.

From the workspace root, run `pnpm dev:web-angular` to serve it at
`http://localhost:5174`. Use `pnpm lint:web-angular`, `pnpm test:web-angular`,
and `pnpm build:web-angular` for isolated checks.
